# Universal Procurement Agent – Operating Manual

This folder contains the operating manual in two language versions.

## Files

- `OPERATING_MANUAL_EN.md` – English version
- `OPERATING_MANUAL_CS.md` – Czech version

## Recommended usage

Use the Czech version for everyday work if your procurement work is mainly in Czech.

Use the English version for international suppliers, multinational teams, or when sharing the framework with English-speaking colleagues.
