# 企业采购报价审核与采购建议 Agent

> 2026-11-02 实施说明：本文件保留原始需求基线。当前V1能力、使用方式和边界以 README.md、DATA_CONTRACT.md 和 VERIFICATION.md 为准。下文“当前状态”和“私密仓库”描述为初始记录；本次实施时GitHub实际返回公开仓库，提交仅含代码和模拟数据。

> 可直接转发给开发方/供应商的需求说明

## 1. 项目背景

企业采购人员目前需要逐家打开、阅读和整理供应商报价。涉及原材料、模具、设备等采购类型时，报价文件格式不统一、比较维度复杂，人工容易出现看错、抄错、漏项和比较口径不一致的问题。

本项目建设一个企业内部使用的采购报价审核与采购建议 Agent，帮助采购人员从多家报价中快速形成可核验的比较结果，并判断最低价是否存在异常。

## 2. 项目目标

系统不能只回答“谁报价最低”，而要回答：

1. 报价单里的信息是否读取正确；
2. 不同供应商的报价是否真正可比；
3. 是否存在漏报、错报、单位错误、税费口径不一致；
4. 最低报价是否明显偏离本批报价、历史采购价或市场参考；
5. 哪些因素导致某供应商综合得分较高；
6. 采购人员下一步应该向供应商确认什么；
7. 是否可以形成条件性的采购建议；
8. 每个结论能否回溯到原始报价证据。

## 3. 第一版范围（MVP）

### 3.1 输入文件

第一版支持：

- Excel 报价单（`.xlsx`）；
- CSV 报价表；
- JSON 结构化报价；
- 历史采购价格 CSV / Excel / JSON；
- 后续扩展 PDF 文本、扫描 PDF、图片和邮件附件。

### 3.2 报价信息抽取

每条报价尽可能抽取：

- 供应商名称；
- 报价日期；
- 报价有效期；
- 物料 / 模具 / 设备名称；
- 物料编码；
- 规格型号；
- 品牌、材质、牌号；
- 数量和单位；
- 含税单价 / 总价；
- 未税单价 / 总价；
- 税率；
- 运费；
- 包装费；
- 安装费；
- 调试费；
- 模具费；
- 付款条件；
- 交期；
- 最小起订量；
- 质保期；
- 供应商备注；
- 原始文件名、页码、行号、单元格或图片区域。

原始数字必须保留证据位置，不能只保留模型整理后的结果。

### 3.3 报价可比性检查

系统需要把比较项目标记为：

- 可直接比较；
- 基本可比但存在条件差异；
- 需要人工确认；
- 不可直接比较。

重点检查：

- 物料 / 设备 / 模具规格是否一致；
- 单位是否一致；
- 数量是否一致；
- 含税和未税口径是否一致；
- 币种是否一致；
- 是否含运费；
- 是否含安装和调试；
- 是否含模具、工装、软件和备件；
- 品牌、材质、牌号和技术参数是否一致；
- 是否存在报价范围缺失。

不可比的报价不能直接参加最终排名，或者必须明确标记为有条件比较。

### 3.4 确定性比价

第一版至少比较：

- 价格；
- 交期；
- 付款周期。

评分权重必须可配置，例如：

```json
{
  "price": 0.5,
  "lead_time": 0.3,
  "payment_terms": 0.2
}
```

输出：

- 每家供应商得分；
- 各维度得分贡献；
- 综合排名；
- 第一名和第二名分差；
- 最低价供应商；
- 最快交期供应商；
- 付款条件最优供应商。

数值计算必须由确定性程序完成，不能让大模型直接心算和排序。

### 3.5 价格合理性分析

系统需要对最低价和异常报价进行分析，至少比较：

1. 本批有效报价中位数；
2. 企业历史采购价格中位数；
3. 同一供应商历史报价；
4. 可获得的市场参考价；
5. 报价范围是否完整；
6. 规格和技术条件是否等效。

输出分类：

- 正常；
- 偏低但可以解释；
- 异常低价，需要确认；
- 偏高但配置或服务更完整；
- 信息不足，无法判断。

示例：

> 供应商 C 报价低于本批有效报价中位数 32%，同时未明确是否包含运费和安装调试费用，且历史价格参考不足，暂不建议直接按最低价定标。

### 3.6 采购建议

建议必须区分：

- 事实；
- 计算结果；
- 假设；
- 风险；
- 建议；
- 需要人工确认的问题。

当综合评分第一名触发异常低价、缺失字段或不可比条件时，系统不得自动输出最终推荐，只能输出：

- 候选供应商；
- 待人工复核；
- 阻断原因；
- 需要补充的供应商确认问题。

## 4. 不同采购类型的扩展规则

### 4.1 原材料

重点比较：

- 牌号；
- 材质；
- 厚度、尺寸；
- 单位和重量；
- 含税价；
- 运费；
- 交期；
- 市场行情；
- 历史采购价。

### 4.2 模具

重点比较：

- 模具类型；
- 产品尺寸；
- 型腔数量；
- 模架；
- 钢材牌号；
- 热处理；
- 加工精度；
- 使用寿命；
- 试模次数；
- 修改次数；
- 交期；
- 维修和售后；
- 是否包含设计、加工、运输和调试。

### 4.3 设备

重点比较：

- 主机型号；
- 产能；
- 精度；
- 功率和能耗；
- 辅助设备；
- 软件；
- 安装；
- 调试；
- 培训；
- 备件；
- 质保；
- 售后响应；
- 付款节点；
- 预计维护成本；
- 全生命周期成本。

不同采购类型不能强行共用一套简单的最低价排序规则。

## 5. 输出结果

系统至少输出：

### 5.1 结构化 JSON

供系统、ERP、SRM 或后续 Agent 使用。

### 5.2 Excel 比价报告

包含：

- 供应商排名；
- 价格和统一口径说明；
- 交期；
- 付款条件；
- 综合评分；
- 异常标记；
- 缺项清单；
- 历史价格对比；
- 原始报价证据位置；
- 采购建议；
- 人工确认事项。

### 5.3 中文采购建议

建议结构：

1. 采购事项摘要；
2. 报价读取结果；
3. 可比性判断；
4. 报价比较；
5. 价格合理性；
6. 供应商风险；
7. 推荐或待复核结论；
8. 建议谈判事项；
9. 需要供应商补充的信息；
10. 证据来源。

## 6. 安全与权限边界

第一版不允许 Agent 自动执行：

- 自动定标；
- 自动下采购订单；
- 自动付款；
- 自动签署合同；
- 自动向供应商承诺价格、数量或交期；
- 自动发送未经人工审核的谈判邮件。

敏感价格、合同和供应商数据必须支持：

- 本地部署或企业内网部署；
- 数据脱敏；
- 权限控制；
- 操作日志；
- 原始文件和结果文件留痕；
- 结果可回溯。

## 7. 验收标准

### 准确性

- 报价金额、币种、单位、税率、交期和付款条件能回溯原文；
- 报价排序与确定性计算结果一致；
- 含税 / 未税和缺项被正确标记；
- 异常低价不会自动形成最终推荐；
- 历史价格偏离能够给出可解释原因。

### 可用性

- 采购人员无需修改代码即可上传一批报价并生成结果；
- 支持至少 2 家、5 家和 10 家以上供应商报价；
- 结果包含 Excel 和中文摘要；
- 失败时明确说明缺少字段或无法比较原因；
- 采购员可以人工修正识别结果后重新计算。

### 可审计性

- 每个关键价格有原始来源位置；
- 评分权重可见；
- 每个异常有具体触发原因；
- 事实、假设、风险和建议分开；
- 不输出无法解释的黑箱推荐。
